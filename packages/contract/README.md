# contract

The Bulb contract: the bulb config JSON Schema, TypeScript types generated from it, and a config loader.

- Schema (source of truth): `src/schemas/bulb-config.schema.json`.
- Types: `src/generated/bulb-config.ts`, generated by `npm run generate`; never edit by hand. A test fails when they
  are stale.

## Loading a config

```ts
import { readBulbConfigFile, parseDurationMs } from '<contract package>';

const config = await readBulbConfigFile('.bulb/config.yaml'); // defaults filled in
parseDurationMs(config.responsibilities['dep-updates']?.min_release_age ?? '0d'); // milliseconds
```

`loadBulbConfig(yamlText)` and `parseBulbConfig(value)` do the same for text and parsed values. Invalid configs throw
`BulbConfigError`, whose `issues` list `{ path, message }` entries such as `budget.per_task_usd: unknown key` or
`notify.on[3]: must be equal to one of the allowed values: ...`. Messages never include config values.

## Defaults

Omitted keys take the defaults written in each key's schema `description`. Required: `version` (must be `1`) and
`responsibilities` (at least one). A responsibility is configured when its key is present, e.g. `ci-fix: {}`; absent
responsibilities get no default object.

| Key | Default |
| --- | --- |
| `engine.provider` | `"anthropic"` |
| `engine.model` | none (the engine adapter picks one) |
| `engine.effort` | `"medium"` |
| `context.include` | `[]` |
| `verify.commands` | `[]` |
| `verify.working_directory` | `"."` |
| `verify.timeout` | `"2h"` |
| `merge.auto_merge` | `false` |
| `merge.require_verified` | `true` |
| `notify.webhook` | none |
| `notify.on` | `["ready", "blocked", "error"]` |
| `responsibilities.<any>.enabled` | `true` |
| `dep-updates.schedule` | `"weekly"` |
| `dep-updates.directories`, `vuln-patch.directories` | `["."]` |
| `dep-updates.allow` | `["patch", "minor"]` |
| `dep-updates.min_release_age` | `"7d"` |
| `dep-updates.hold` | `{}` |
| `dep-updates.group` | `"weekly"` |
| `ci-fix.attempts` | `2` |
| `ci-fix.max_diff_lines` | `200` |
| `budget.per_task_cad` | `1` |
| `budget.per_task_minutes` | `15` |
| `safety.never_touch` | `[".env*", "**/secrets/**"]` |
| `safety.never_push_default_branch` | `true` |
| `safety.never_force_push` | `true` |
| `safety.workflow_files` | `"blocked"` (the only allowed value) |

`min_release_age` defaults to 7 days, the chosen MVP default; a repo can set its own (Personal-Website uses `14d` in
its config).

`notify.webhook` is kept as an opaque string: the loader does not interpolate `${{ ... }}`; resolving it is the
reporter's job.

`extends` and `uses:` are reserved for inherited defaults and third-party responsibilities later; for now they are
rejected as unknown keys like any other.

## Durations

`verify.timeout` and `min_release_age` are `<integer><unit>` with unit `m`, `h` or `d` (`0d` allowed only for
`min_release_age`).
