# bulb-agent

Dormant caretaker agents for your repos. A bulb costs nothing while idle, wakes on a schedule or an event (a
Dependabot PR, a security alert, a failed check), does small upkeep work end to end, and only reaches you when it
needs you.

Status: design. See [`docs/vision.md`](docs/vision.md) and [`docs/mvp.md`](docs/mvp.md).
